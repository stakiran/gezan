# gezan
<img width="1127" height="610" alt="Image" src="https://github.com/user-attachments/assets/2913d7c7-5695-4aa1-b9c1-b33e0f909956" />

下山マイクラ。アンプリファイド100マス世界で丸石だけで最高点→地上を目指す。

Minecraft (Java Edition) 用の Fabric MOD です。`/gezan` コマンドひとつで、プレイヤーの周囲 100×100 マスにワールドボーダーを敷き、その中の最高点から地上 (y<=64) まで降りるタイムを競うミニゲームが始まります。

[mopup](https://github.com/stakiran/mopup) をベースにしています。

## 動作環境

| 項目 | バージョン |
| --- | --- |
| Minecraft | 1.21.11 |
| Fabric Loader | 0.19.0 以上 |
| Fabric API | 0.141.6+1.21.11 (1.21.11 向けのもの) |
| Java | 21 以上 |

## 遊び方

### インストール

1. [Fabric Loader](https://fabricmc.net/use/installer/) を Minecraft 1.21.11 向けにインストールする
2. [Fabric API](https://modrinth.com/mod/fabric-api) の 1.21.11 向け jar を `.minecraft/mods/` に入れる
3. この MOD の jar（`gezan-x.y.z.jar`）を `.minecraft/mods/` に入れる
4. Fabric のプロファイルで Minecraft を起動する

マルチプレイの場合はサーバー側に MOD を入れてください。クライアント側には不要です（ボスバーやタイトルはバニラの機能で表示しています）。

### ワールドの用意

- ワールドタイプを **アンプリファイド** にして新規ワールドを作る
    - アンプリファイドでなくてもゲームは始まりますが、高低差が小さくなり面白くないので警告が出ます
- ゲームモードは何でも構いません。開始時に自動でサバイバルに切り替わります
- コマンドに権限要件はないので、チートを有効にする必要はありません

### ゲーム開始

チャットで次を実行します。

```
/gezan
```

すると次の順で自動セットアップされます。

1. アンプリファイドかどうかを確認し、違えば警告を出す
2. 全員をクリエイティブにし、実行者を中心に 100×100 のワールドボーダーを敷く
3. ボーダー内の最高点を探す（葉っぱは除外。足場になるブロックの中で一番高い場所）
4. 最高点に赤いベッドを置き、全員のリスポーン地点にする
5. 時刻を真夜中で固定し、キープインベントリをオンにする
6. 全員を最高点にテレポートし、初期アイテムを配布し、体力・空腹・経験値をリセットする
7. 全員をサバイバルにしてゲーム開始

開始時にチャットへシード値と開始地点の座標が表示されます。クリックでクリップボードにコピーできるので、同じコースを再挑戦したり人と共有したりするときに使ってください。

`/gezan` はゲーム中や勝利後にいつ実行しても構いません。その場で現在地を中心に作り直すので、リセットを兼ねています。

### 初期アイテム

ホットバーのみ。インベントリは開始時に空にされます。

| スロット | アイテム |
| --- | --- |
| 1 | 松明 ×64 |
| 2〜7 | 丸石 ×64 が 6 スタック |
| 8 | 松明 ×64 |
| 9 | 焼き牛肉 ×8 |

### 勝利条件

**足元の y 座標が 64 以下の場所に、5 秒間とどまり続ける**と勝利です。一瞬でも y>64 に戻るとカウントはゼロからやり直しです。

勝利するとタイムと規模、高低差がタイトルとチャットに表示され、全員がスペクテイターになります。もう一度遊ぶなら `/gezan` を実行してください。

### 死亡条件

通常の死亡に加えて、次の行動も即死になります。

- **水に触れる**（水に飛び込んで無傷で降りるのを防ぐため）
- **原木・板材を入手する**（道具や足場づくりを防ぐため。該当アイテムは没収されます）
- **開始地点のベッドを壊す**（全員が死亡し、ベッドは自動で元に戻ります）

死んでもゲームは終わりません。キープインベントリがオンなので手持ちはそのまま、開始地点のベッドからリスポーンして再挑戦です。敗北はなく、誰かが勝つまで続きます。

### 画面表示

ゲーム中は画面上部のボスバーに次が表示されます。

- 経過時間
- 現在の Y 座標と、地上までの残り高さ
- 地上到達後は勝利までのカウントダウン（バーが緑になる）
- 規模

バーの長さは下山の進捗（開始地点から地上までのどのあたりにいるか）です。

### 規模について

規模は mopup と同じ計算式で、ボーダー内の y>=64 で敵モブが湧ける場所の数から求めています。屋外 1 マスを 1、屋内・洞窟 1 マスを 4 として合計し、100 で割った値です。コースの複雑さの目安として、タイムと一緒に記録してください。
